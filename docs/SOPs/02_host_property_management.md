# SOP: Host Property Management

## Overview
Process for hosts to list properties, manage availability, pricing, and reservations.

---

## Step 1: Create New Listing
**Actor:** Host/Owner  
**Duration:** 30-60 minutes

### 1.1 Basic Info
1. Host logs into myUNO dashboard → "My Properties" → "+ Create Listing"
2. Host enters:
   - Property name (unique)
   - Location (country, region, address)
   - Coordinates (auto-mapped or manual)

### 1.2 Property Details
1. Host selects:
   - Room type (entire home, private room, shared room, etc.)
   - Bedrooms & bathrooms count
   - Max guest capacity
   - Category (villa, apartment, townhouse, etc.)

### 1.3 Photos & Description
1. Host uploads minimum 5 photos:
   - Cover photo (living area)
   - Bedrooms (minimum 1)
   - Bathrooms
   - Common areas
2. Host writes description:
   - Key features
   - Layout highlights
   - Nearby attractions

### 1.4 Amenities & House Rules
1. Host checks amenities offered:
   - WiFi, air conditioning, heating
   - Kitchen, laundry, parking
   - Pool, gym, workspace, etc.

2. Host sets house rules:
   - Guest limits per room
   - Quiet hours
   - Smoking/pets policy
   - Party policy

### 1.5 Pricing & Policy
1. Host sets:
   - Base price per night (THB)
   - Cleaning fee (one-time)
   - Weekly discount (%)
   - Monthly discount (%)
   - Min/Max night stays

2. Host selects cancellation policy:
   - Flexible: Full refund until check-in
   - Moderate: Full refund 7+ days prior
   - Strict: Full refund 30+ days prior

3. Host chooses booking mode:
   - **Instant Book:** Auto-confirm reservations
   - **Request-to-Book:** Host approves each booking

**Exit:** Listing created in draft mode → **Step 2**

---

## Step 2: Verify & Activate Listing
**Actor:** Host, Admin  
**Duration:** 1-2 hours

### 2.1 Legal Verification
1. Admin team reviews:
   - Property location & zoning (commercial use allowed?)
   - License status (if required)
   - Insurance coverage

2. Admin confirms:
   - Property is live/available
   - Max occupancy complies with local regs
   - Safety items documented (fire extinguisher, first aid, etc.)

### 2.2 Photos Review
1. Admin validates:
   - Minimum 5 photos submitted
   - Photos show property accurately
   - No misleading images

### 2.3 Activation
1. Admin marks listing as **approved**
2. Listing goes live on platform
3. Host receives confirmation email

**Exit:** Listing is discoverable & bookable → **Step 3**

---

## Step 3: Manage Availability & Pricing
**Actor:** Host  
**Duration:** Ongoing

### 3.1 Block Dates
1. Host navigates to "Calendar"
2. Host selects date range to block (e.g., personal use, maintenance)
3. Host enters reason (optional)
4. Blocked dates appear gray in booking calendar
5. No bookings can occur on blocked dates

**Unblock:** Host clicks blocked date → "Unblock"

### 3.2 Seasonal Pricing
1. Host navigates to "Pricing Rules"
2. Host creates rule:
   - Name (e.g., "High Season")
   - Date range (start, end)
   - Price per night (override base)
   - Label (shown to guests)
3. System applies rule to all overlapping bookings

**Example:**
- Base price: 2,000 THB/night
- High season rule (Dec 15–Jan 10): 3,500 THB/night
- A booking on Dec 20 charged at 3,500 THB

### 3.3 Length-of-Stay Discounts
1. Host sets (globally):
   - Weekly discount: 10% (7+ nights)
   - Monthly discount: 20% (28+ nights)
2. System auto-applies when guest books

---

## Step 4: Manage Reservations
**Actor:** Host  
**Duration:** Varies

### 4.1 Incoming Bookings (Request-to-Book)
1. Host receives notification: "New booking request"
2. Host reviews:
   - Guest name & profile
   - Dates & party size
   - Guest reviews/history
   - Stated reason (if provided)

3. Host **approves** or **declines** within 24h
   - **Approve:** Reservation moves to pending (guest pays)
   - **Decline:** Guest notified, dates freed, guest can retry other listings

**SLA:** Must respond within 24h (auto-decline after 24h)

### 4.2 Confirmed Reservations
1. Host views confirmed bookings in calendar
2. Host can:
   - Message guest (via in-app chat)
   - Update check-in instructions
   - Note any special requests
   - Flag if guest cancels

### 4.3 Cancellations
1. Guest initiates cancellation
2. System computes refund per policy
3. Host notified (no action needed)
4. Guest receives refund within 5-7 days
5. Dates immediately freed for rebooking

---

## Step 5: Check-In & Check-Out
**Actor:** Host, Guest, Staff  
**Duration:** Varies

### 5.1 Pre-Arrival
1. System sends host reminder: "Booking arrives in 24h"
2. Host confirms:
   - Unit is cleaned & ready
   - Keys/codes prepared
   - Utilities functioning
   - WiFi tested

### 5.2 Check-In
1. Guest arrives
2. Host (or staff) meets guest:
   - Verifies identity
   - Hands over keys/codes
   - Tours property
   - Explains appliances, WiFi, emergency contacts

3. Host marks "Checked In" in system

### 5.3 Check-Out
1. Guest departs on checkout date
2. Host (or staff) inspects:
   - Cleanliness
   - Damage or missing items
   - Utilities off (as required)

3. Host returns keys
4. Host marks "Checked Out" in system
5. If damage found → damage claim initiated

---

## Step 6: Handle Issues & Maintenance
**Actor:** Host, Ops Staff  
**Duration:** Varies

### 6.1 Guest Complains
1. Guest messages host with issue
2. Host responds within 2 hours
3. Host options:
   - **Quick fix:** Host fixes it or sends staff
   - **Major issue:** Escalate to ops team
   - **Damage claim:** Guest liable (deducted from deposit if applicable)

### 6.2 Maintenance Needed
1. Host navigates to "Maintenance Requests"
2. Host creates request:
   - Issue description
   - Urgency (routine, urgent, emergency)
   - Preferred dates

3. System assigns maintenance staff
4. Staff schedules with host
5. Issue marked resolved when complete

### 6.3 Emergency (No Water, No AC, etc.)
1. Host or guest notifies ops: "+66-XXXX-XXXX" (24/7 line)
2. Ops assigns staff within 1 hour
3. Emergency maintenance completes or unit taken offline
4. Guest may receive partial refund if stay impacted

---

## Step 7: Financial Settlement
**Actor:** Host, Finance Team  
**Duration:** Monthly

1. At end of each month, system generates **Owner Statement**:
   - Gross revenue (all booking payments)
   - Service fees deducted
   - Cleaning/maintenance costs
   - Insurance & utilities (if applicable)
   - **Net owner payout**

2. Statement published on day 7 of following month
3. Payout transferred to host's bank account by day 10
4. Host can view statement in "Earnings" dashboard

## Performance Metrics & Superhost Status

### Tracked Metrics
- **Response rate:** % of inquiries answered within 24h
- **Response time:** Avg hours to respond
- **Cancellation rate:** % of cancellations by host
- **Guest rating:** Avg rating across all bookings
- **Review accuracy:** Photos match property

### Superhost Criteria (yearly)
- ✅ Response rate ≥ 90%
- ✅ Avg response time ≤ 24h
- ✅ Host cancellation rate < 1%
- ✅ Avg rating ≥ 4.6/5 stars
- ✅ 10+ completed bookings

**Benefit:** Superhost badge displayed on listing, higher visibility
