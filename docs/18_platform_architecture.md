# Платформа и федерация

Актуализировано по main 2026-10-16. Asset/stay/service/finance/CRM domains работают в одном app/store. Layantara adapter использует environment mappings/inbox/checkpoints и authority gating. Внешние stores/commands не активируются самим наличием модели. iCal не заменяет full ARI.
