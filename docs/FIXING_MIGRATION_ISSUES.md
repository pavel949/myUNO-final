# 🔧 Как чинить проблемы с Prisma миграциями

## Проблема

Миграция `1_add_analytics_tables` застряла в середине применения. Система не может двигаться дальше.

## Решение

### Способ 1️⃣: Через Vercel (РЕКОМЕНДУЕТСЯ)

Если приложение развёрнуто на Vercel, это самый безопасный способ:

1. Перейди на **vercel.com**
2. Открой проект **myUNO-final**
3. Найди кнопку **"Deployments"** → **"Settings"** → **"Functions"** или **"CLI"**
4. Запусти команду:
   ```bash
   npx prisma migrate resolve --rolled-back 1_add_analytics_tables
   ```

### Способ 2️⃣: Локально (на своём компьютере)

**Требования:**
- NODE_JS установлен
- `.env` файл с правильным `DATABASE_URL` (из Supabase)

**Шаги:**

```bash
# 1. Перейди в папку проекта
cd myUNO-final

# 2. Установи зависимости (если нужно)
npm install

# 3. Запусти скрипт для чинки
bash scripts/fix-migration.sh
```

Или вручную:

```bash
npx prisma migrate resolve --rolled-back 1_add_analytics_tables
npm run build
```

### Способ 3️⃣: Через GitHub Actions (АВТОМАТИЧЕСКИ)

Я создал GitHub Action, который будет это чинить автоматически.

**Как запустить:**
1. Перейди на GitHub
2. Открой репозиторий
3. Найди вкладку **"Actions"**
4. Выбери **"Fix Migration"**
5. Нажми **"Run workflow"**
6. Система сама всё починит! 🤖

---

## Почему это произошло?

**Техническая причина:**
- Миграция начала применяться к базе данных
- Что-то прошло не так (может быть, проблема с сетью или базой)
- Миграция "зависла" - система не знает, была ли она применена полностью или нет

**Наше решение:**
- Мы говорим Prisma: "Забудь эту миграцию, она не была применена успешно"
- После этого Prisma может снова применить её правильно

## Если не работает

### Ошибка: "Can't reach database server"

**Причина:** Нет доступа к Supabase

**Решение:**
1. Проверь, что `DATABASE_URL` в `.env` правильный
2. Проверь, что база данных запущена на Supabase.com
3. Проверь интернет соединение

### Ошибка: "Migration not found"

**Это хорошо!** Это значит, миграция уже была откачена. Дальше нужно:
```bash
npm run build
```

### Ошибка: "Permission denied"

**Причина:** Нет прав на выполнение скрипта

**Решение:**
```bash
chmod +x scripts/fix-migration.sh
bash scripts/fix-migration.sh
```

## Безопасность

- Не удаляет никакие данные
- Только отмечает миграцию как "откачена"
- После этого Prisma может применить её заново
